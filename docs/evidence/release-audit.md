## Responsive regression

A real-browser smoke at 360 CSS pixels exposed a rainy forecast badge whose
right edge reached 365.546875px. The root scroll-width assertion could be
clipped by the body's overflow rule, so the touch-mobile Playwright journey now
also checks the visible badge's bounding rectangle directly. The assertion
failed before the correction and passes after the mobile badge was constrained
to its container and allowed to wrap; the full desktop/mobile suite remains
green.
